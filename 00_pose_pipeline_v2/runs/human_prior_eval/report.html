5. EasyMocap / SMPL status

The EasyMocap CUDA SMPL module imports successfully under Torch 2.8 / CUDA 12.8. Reproducible setup, private-asset ignore rules, and a CUDA validator are ready. Formal fitting has not run because SMPL_NEUTRAL.pkl is license-controlled and absent.

This is an external asset gate, not an accuracy failure. Follow docs/smpl_asset_setup.md and obtain the model only from the official SMPL website.

6. Conclusions and next steps

  1. Retain deterministic PyTorch FP32 YOLOv8m + SKT as the formal baseline.
  2. After official SMPL upload, run only the 40-frame Fanbo4/Fanbo7 reprojection and semantic gate before any longer job.
  3. If SMPL also fails, prioritize project-specific bundle adjustment with joint limits and temporal priors over additional monocular model replacement.
  4. Use FoundationStereo only as an occlusion/depth diagnostic, not as a joint-semantic replacement.
  5. Select parameters from geometry and temporal stability; use Xsens only for final agreement reporting.
